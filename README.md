    - `Magnet RAM Capture` from [Magnet RAM Capture](https://www.magnetforensics.com/resources/magnet-ram-capture/)
    - `Magnet Process Capture` from [Magnet Process Capture](https://www.magnetforensics.com/resources/magnet-process-capture/)
